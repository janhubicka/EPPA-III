# Arbitrary selected copies in the introductory classification

Every induced copy of the required base in cases (3) and (4a–f) lies in the orbit of the canonical selected copy under the host automorphism group. A host automorphism carrying the canonical copy to the given copy transports the EPPA property, so the designated-embedding proofs establish sufficiency for the abstract isomorphism types in these cases. Complementing the host and selected graph preserves this orbit property and the EPPA property.

## Generalized clique covers and homogeneous doubles

Write the two layers as $A_1,\ldots,A_s$ and $B_1,\ldots,B_s$, with every indexed clique of size $t$. Let the selected graph be an induced $sK_t$. The symbols $X=0,1,M,\overline M$ denote respectively the empty, complete, matching, and complementary matching cross relation at equal indices. $Y$ controls the cross relation at different indices.

- **$Y=0$.** For $X=0$ the host is $2sK_t$, and component permutations move any selection of $s$ components to the canonical one. The same argument applies to $X=\overline M$ at $t=1$. Otherwise the $s$ index blocks $A_i\cup B_i$ are connected. Each block can contain at most one selected clique, since two would exhaust it and leave no edge between them. Thus each block contains one selected clique. When $X=1$, the block is $K_{2t}$ and all $t$-cliques are equivalent. When $X=M$, any $t$-clique for $t\geq 3$ lies in one layer, and the layer swap exchanges the two possibilities. For $t=2$ the block is an edge-transitive four-cycle, and for $t=1$ it is a single edge. When $X=\overline M$, the block is a complete graph with a perfect matching removed. Each $t$-clique is a transversal of the nonedge pairs, and independent pair swaps act transitively on such transversals. These block automorphisms act independently.
- **$Y=1$, $s\geq 3$.** If all selected cliques are contained in layers and both layers are used, selected cliques in opposite layers must have the same index. There can then be at most two cliques. If one selected clique meets both $A_i$ and $B_j$, every other selected clique can meet only $A_j\cup B_i$. The case $i=j$ leaves no room for another clique, because a vertex in either of those two positions is adjacent to the selected vertices on its own side. When $i\ne j$, $A_j\cup B_i$ is a clique, so again there are at most two selected cliques. Both arguments force the selection to be an entire layer when $s\geq3$.
- **$Y=1$, $s=2$.** The host has two complete sides $A_1\cup B_2$ and $A_2\cup B_1$, and the cross edges between them come from the two diagonal relations $X$. For $X=0$, an induced $2K_t$ selects $t$ vertices from each complete side, and the two independent symmetric groups act transitively. For $X=M$, the edges between the complete sides form a perfect matching. An induced $2K_t$ selects $t$ vertices on each side, chooses no matched pair, and therefore contains one endpoint from each matching pair. A simultaneous permutation of the $2t$ matched coordinates can send the size-$t$ choice on the first side to any other. For $X=1$, a mixture of both layers with pure cliques of the same index is impossible, and two mixed selected cliques would have adjacent vertices at a common index in opposite layers. Therefore the copies are exactly the complete original layers. For $X=\overline M$, $t=1$ reduces to $X=0$. At $t\geq2$, both $t$-cliques in a genuinely mixed selection must meet both original layers. A pure clique in the other component would use an entire indexed $t$-clique, whose vertices include a neighbour of any selected opposite-side vertex at that index. For two mixed cliques, the nonempty selections from $A_i$ and $B_i$ belong to different components at each index $i$; all coordinate pairs between them must be equal. Thus all four nonempty fragments are singletons, and $t=2$. In this case $\overline M$ is itself a perfect matching on each diagonal block, so the same simultaneous permutation argument applies.
- **$s=1$.** There are no off-diagonal blocks, and the single-block argument for $Y=0$ applies.

For case (3c), use the two host cliques of size $n=l+k$ joined by matching edges. A selected component meeting both host cliques would have to be a single cross matching edge, and every other host vertex is adjacent to one of its endpoints. This would contradict the presence of the second selected component. Thus the two selected components lie in opposite host cliques and select exactly one endpoint of every matching edge. The same simultaneous permutation action is transitive on these choices.

In $2G$, a connected selected $G$ lies in one copy and exhausts it. Every disconnected homogeneous graph is a disjoint union of equal cliques. A nonadjacent pair in a single component could otherwise be sent to a pair in distinct components by homogeneity, and transitivity forces equal clique sizes. Thus $2G$ in the disconnected case is covered by the component-permutation argument. For Taylor doubles, if $G=sK_t$ the host is the cover with $X=0,Y=1$. If $G=\overline{sK_t}$, the complement of its Taylor double is the cover with $X=M,Y=1$. Gardiner's remaining homogeneous bases are $C_5$ and $R_3$, treated below.

## Five-cycle, rook, and Wagner hosts

- In the five-prism, an induced five-cycle meeting both layers must have exactly two cross edges. The segments in the two layers then have lengths one and two. The endpoints of the length-two segment are adjacent in its layer because the corresponding endpoints of the length-one segment are adjacent in the other layer. This gives a chord. The two possible single-layer copies are exchanged by the layer swap.
- In either rook matching model, a selected rook graph meeting both layers would have a nonempty cut consisting only of matching edges. A split row or column triangle contributes two cut edges at one vertex. Hence all row and column triangles would have to lie entirely on one side or the other. Since row and column triangles intersect, the selection lies in one layer. In the graph with complementary upper adjacency, a self-complementing rook coordinate map combined with the layer swap exchanges the two choices. The disjoint cycle and rook cases follow because the selected graphs are connected.
- In the complement of the two-clique extension, the host has pairs of nonadjacent twins, one pair for each vertex of the underlying cycle or rook graph. The base graphs have distinct open neighbourhoods at different vertices. A selected copy therefore contains one endpoint of each pair, and independent twin swaps carry any such copy to the canonical one.
- In a Taylor double, the two vertices in a mate pair are nonadjacent with no common neighbour. Both $C_5$ and $R_3$ have a common neighbour at every distinct nonadjacent pair, so a selected copy of either graph is a transversal. Every isomorphism $f$ from the canonical base to the induced transversal, of the form $x\mapsto(t_x,\sigma(x))$, extends to the host by $(b,x)\mapsto (b\oplus t_x,\sigma(x))$. For distinct fibres the adjacency rule agrees with the induced transversal rule when both layer bits are equal, and toggles when exactly one layer bit changes.
- Label the Wagner graph by an eight-cycle and the four opposite chords. An induced $2K_2$ cannot use the cycle edge $01$: the only other two vertices adjacent to neither endpoint are $3,6$, which are nonadjacent. By rotation no cycle edge occurs. Each induced $2K_2$ consists of opposite chords, and the two possible pairs of chords are exchanged by a rotation.

The accompanying `check_imprimitive_embedding_orbits.py` independently enumerates all induced copies of the required size and every host automorphism in the finite cases. It uses degree and neighbour-degree invariants to prune a bijective backtracking search, checks adjacency in both directions at every assignment, and asserts that the canonical orbit equals the copy set. The log includes the distinct copy counts for each model.
